# Hospital Resource Optimization Service

## 📌 Project Overview
This repository hosts the live service HTML application for hospital resource optimization.
It provides an accessible interface to visualize and interact with allocation models developed in the Hospital Resource Optimization Notebook.

## 🎯 Purppose/Target
- Deliver optimization results through a web‑based interface.

- Enable hospital administrators and stakeholders to explore resource allocation scenarios without running code.

- Provide lightweight, accessible demos for regions with limited bandwidth


## ⚙️Features
Interactive UI: Adjust parameters (beds, staff, patient demand).

Visualization: Charts showing allocation outcomes and bottlenecks.

Accessibility: Lightweight HTML/CSS/JS design for fast loading.

Integration: Built on outputs from the optimization notebook.
